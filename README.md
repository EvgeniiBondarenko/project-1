# Проект разработки банковского приложения
## Модуль process_bank

Модуль `process_bank` предоставляет функции для обработки банковских операций. Он включает в себя две основные функции:

1. **process_bank_operations(data: List[Dict[str, str]], categories: List[str]) -> Dict[str, int]**
   - **Описание**: Подсчитывает количество банковских операций по заданным категориям.
   - **Параметры**:
     - `data`: Список словарей, каждый из которых представляет банковскую операцию с ключом `description`.
     - `categories`: Список категорий, по которым необходимо произвести подсчет операций.
   - **Возвращает**: Словарь, где ключом является категория, а значением - количество операций.

2. **process_bank_search(data: List[Dict[str, Any]], search: str) -> List[Dict[str, Any]]**
   - **Описание**: Осуществляет поиск банковских операций по описанию.
   - **Параметры**:
     - `data`: Список словарей с данными о банковских операциях.
     - `search`: Строка для поиска в описании операций.
   - **Возвращает**: Список словарей, содержащих только найденные операции.
